# R3 literature-language audit snapshot

Date: 2026-08-17

Scope: the rendered literature map and its literature-position table. This is
an editorial evidence audit, not a claim that the seed search is exhaustive.

## Decisions

| Language risk | Decision | Evidence boundary |
|:--|:--|:--|
| prevalence or industrial-deployment claims | Removed unsupported wording such as “most widely deployed”; topology processing is described through the CIM/PowSyBl records and the Farrokhabadi--Vanfretti primary study | No market-share, utility-adoption, or deployment-frequency claim is made |
| maturity claims | Recast the attention/gap figure as a provisional assessment of the coded seed matrix, not a bibliometric score | The 29-record matrix remains single-coded and non-exhaustive |
| “mainstream” literature | Replaced with “the cited power-system reduction literature” and attached the Ward/Kron/REI family references | The statement is a taxonomy of the cited family, not a corpus-wide prevalence result |
| “structure-preserving” terminology | Retained only as source-specific terminology or as a clearly labelled project taxonomy; the table states what each source establishes and what remains open | The phrase does not imply a common formal definition across papers |
| source authority | Added a source-type legend separating primary papers, standards, official software documentation, repository reproductions, and project proposals | Source type does not promote a repository result to peer review or external validation |

## Result

The literature map now either attaches broad technical statements to a cited
source or labels them as provisional synthesis. It does not use the audited
language to claim exhaustive coverage, industrial prevalence, or a universal
meaning of “structure-preserving.” The database-export, citation-chasing,
deduplication, and independent human double-coding tasks remain separate R3
work items.
